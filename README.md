# DeepSeaExplorer
A swimming simulation game featuring dual input modes: traditional keyboard controls and real-time gesture-based interaction using two webcams.

## Acknowledgements

This project is built upon the excellent work from the following repositories:

* **[OpenPose](https://github.com/CMU-Perceptual-Computing-Lab/openpose):** A real-time multi-person keypoint detection framework.
* **[UDP](URL_HERE):** A lightweight solution for UDP-based full communication between Unity (C#) and Python 3.
* **[keyboard](https://github.com/boppreh/keyboard):** A Python library providing full global keyboard control.
